# مودم زيد (Modem Zaid) — إدارة ذكية وموحدة لمودمات يمن فورجي وسبيد فورجي والراوترات

تطبيق أندرويد أصيل مبني بـ **Flutter** يتعرف تلقائياً وبدقة على أي مودم أو راوتر متصل بالهاتف عبر الواي فاي (مع ربط كامل للعملية بشبكة الواي فاي عبر `ConnectivityManager` في أندرويد حتى عند تفعيل بيانات الهاتف الخلوية في نفس الوقت)، ويقوم بترجمة واجهاته ومميزاته وبروتوكولاته برمجياً إلى واجهة عربية موحدة وحقيقية 100%.

## أبرز المميزات المحدثة (v1.5.0)
- **دعم أصيل وسريع لمودمات يمن فورجي وسبيد فورجي (`Yemen 4G CPE`، `MIFI-L818A`، `Star Speed 4G`، `Olax`، `ZLT`، `Huawei`، `ZTE`، `SAM`، `Vortex`، `Cool 4G`، `Jetpack`)**:
  - فصل دقيق 100% بين مودمات `Notion Duster` (`MIFI-L818A` على `192.168.43.1`) ومودمات `Marvell UAPXC` (`Yemen 4G CPE` على `192.168.0.1`) مع إنهاء فوري لقراءة مقابس HTTP (الدخول في ~1.5 ثانية).
  - ربط أصيل ومحدث تلقائياً بواجهة الواي فاي في أندرويد حتى عند تفعيل وضع الطيران مع الواي فاي أو التبديل بين مودمين يحملان نفس العنوان `192.168.0.1`.
- **التعرف الذكي على الشركة المصنعة وطراز المودم وطريقة الدخول**:
  - استخراج اسم الشركة والطراز الحقيقي عبر `UPnP SSDP` وواجهات تعريف الجهاز لأكثر من 35 شركة مصنعة، مع نافذة استعراض جميع المودمات المدعومة.
  - كشف تلقائي للمودمات التي تطلب **كلمة المرور فقط** وإخفاء حقل اسم المستخدم تلقائياً.
- **بيانات حقيقية 100% بدون وضع ديمو أو تعليق على أرقام سابقة**:
  - إزالة وضع المحاكاة (الديمو) بالكامل وعرض رقم خدمة المودم المتصل حالياً فقط (`MSISDN / MDN`).
- **إدارة وحظر فعلي للأجهزة المتصلة والسابقة عبر `MAC Address`**:
  - عرض الأجهزة المتصلة الآن والسابقة والمحظورة مع التحقق الفعلي من ذاكرة المودم بعد تنفيذ الحظر أو فك الحظر.

## البنية البرمجية
- `android_overrides/MainActivity.kt` & `lib/services/wifi_network_binder.dart`: قناة أندرويد الأصلية لقراءة بوابة الواي فاي الحقيقية وربط اتصال التطبيق بالواي فاي.
- `lib/models/modem_models.dart`: نماذج البيانات الموحدة وأنماط المصادقة (`ModemAuthMode`) والتحقق الصارم من رقم الخدمة.
- `lib/services/modem_detector.dart`: الفحص السريع والدقيق والتعرف الذكي على الشركة والطراز ونوع تسجيل الدخول.
- `lib/services/adapters/`: محولات البروتوكولات الحقيقية (`marvell_uapxc_adapter.dart`, `notion_mifi_adapter.dart`, `zte_goform_adapter.dart`, `huawei_hilink_adapter.dart`, `universal_translator_adapter.dart`).
- `lib/services/app_controller.dart`: إدارة الجلسة، مراقبة تغيّر الواي فاي تلقائياً، ومنع تداخل بيانات المودمات.
- `lib/widgets/devices_manager_sheet.dart` & `lib/widgets/supported_modems_sheet.dart`: لوحة إدارة الأجهزة وقائمة المودمات المدعومة.
