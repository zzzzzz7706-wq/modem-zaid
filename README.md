# مودم زيد (Modem Zaid) — إدارة ذكية وموحدة لمودمات يمن فورجي والراوترات

تطبيق أندرويد أصيل مبني بـ **Flutter** يتعرف تلقائياً على المودم المتصل بالهاتف عبر الواي فاي، ويقوم **بترجمة واجهاته ومميزاته وبروتوكولاته برمجياً** إلى واجهة عربية داكنة موحدة وسلسة (دون فتح صفحات الويب الخام للمودم).

## أبرز المميزات
- **كشف تلقائي وبصمة ذكية للمودم (`ModemDetector`)**:
  - يكتشف عنوان البوابة الافتراضية تلقائياً (`192.168.43.1`, `192.168.0.1`, `192.168.8.1`, `192.168.1.1`, إلخ) ويتعرف على نوع المودم فور فتح التطبيق.
- **محرك ترجمة متعدد البروتوكولات (`Adapters`)**:
  - **Notion / Marvell / ASR XML-RPC (`xml_action.cgi` + `Digest Auth`)**: متوافق بالكامل ومفحوص فعلياً مع مودمات `L818A`، فورتكس (`Vortex`)، سام (`SAM M50 / M50 Pro`)، `M028T`، `L02H`، وكول فورجي.
  - **ZTE / ZLT / Olax CGI (`goform`)**: يدعم مودمات `ZTE MF927`, `MF293N`, `ZLT M30/M90 Pro`, `Olax MT80 / MF982`.
  - **Huawei / Brovi HiLink (`/api/...`)**: يدعم مودمات هواوي وبروفي.
  - **المترجم الذكي الشامل (`UniversalTranslatorAdapter`)**: يترجم صفحات وخصائص أي راوتر أو مودم آخر إلى بطاقات عربية نظيفة داخل التطبيق.
- **جميع شاشات التحكم الاحترافية**:
  - **شاشة الدخول السريع**: مع شارة الاتصال الحية، الدخول بالبصمة، تبديل الثيمات، وزر **استعلام رصيد يمن فورجي** المباشر (`svc.ptc.gov.ye/4g`) مع جلب رمز التحقق وعرض النتيجة داخل التطبيق.
  - **لوحة الرئيسية الحية**: عدادات دائرية لنسبة البطارية وحالة الشحن، استهلاك البيانات (تنزيل/رفع ووقت الجلسة بالثانية)، قوة الإشارة مع النطاق الترددي (`B28`, `B3`...)، عدد الأجهزة المتصلة، وشبكة اختصارات قابلة للتخصيص.
  - **إعدادات المودم المتكاملة (4 أقسام)**:
    1. **نظرة سريعة**: معلومات الجهاز والشريحة، إحصائيات الجلسة، وإدارة الأجهزة المتصلة (مع شارة `أنت`، التسمية، والحظر الفوري).
    2. **إعدادات الشبكة**: تعديل الواي فاي (SSID، كلمة المرور، إخفاء الشبكة، الحد الأقصى للأجهزة) + **تثبيت ترددات الأبراج يدوياً (`Band Lock`)**.
    3. **التحكم**: تفعيل وضبط تحديد سرعة التنزيل والرفع لتوفير الباقة.
    4. **إعدادات عامة**: تغيير كلمة مرور المدير، التحكم بظهور الباركود في شاشة المودم + توليد باركود الواي فاي على الهاتف، وإعادة/إيقاف تشغيل المودم عن بُعد.
  - **التشخيص ورادار البرج**: قراءة حية لقيم `RSRP`, `SINR`, `RSRQ`, `RSSI`, `PCI`, `Cell ID` لتوجيه المودم لأفضل تغطية + فحص `Ping` الفوري + قراءة رسائل الشريحة `SMS`.

## البنية البرمجية
- `lib/models/modem_models.dart`: نماذج البيانات الموحدة وقدرات المودم.
- `lib/services/modem_detector.dart`: الكشف التلقائي عن البوابة وبروتوكول المودم.
- `lib/services/adapters/`: محولات البروتوكولات (`notion_mifi_adapter.dart`, `zte_goform_adapter.dart`, `huawei_hilink_adapter.dart`, `universal_translator_adapter.dart`, `demo_modem_adapter.dart`).
- `lib/services/yemen4g_balance_service.dart`: خدمة الاستعلام المباشر عن رصيد يمن فورجي.
- `lib/screens/` & `lib/widgets/`: واجهات المستخدم والعدادات الرسومية التفاعلية.
