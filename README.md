# مودم زيد (Modem Zaid) — إدارة ذكية وموحدة لمودمات يمن فورجي والراوترات

تطبيق أندرويد أصيل مبني بـ **Flutter** يتعرف تلقائياً على المودم المتصل بالهاتف عبر الواي فاي (مع ربط مباشر بواجهة `wlan0` حتى عند تفعيل بيانات الهاتف الخلوية في نفس الوقت)، ويقوم **بترجمة واجهاته ومميزاته وبروتوكولاته برمجياً** إلى واجهة عربية موحدة ودقيقة دون فتح صفحات الويب الخام للمودم.

## أبرز المميزات المحدثة (v1.2.0)
- **استخراج وعرض رقم خدمة يمن فورجي بدقة (`MSISDN / MDN`)**:
  - قراءة رقم خط الخدمة من المصادر المعتمدة داخل المودم مع تحقق صارم يمنع الخلط بين رقم الخدمة والرقم التسلسلي للجهاز (`IMEI`) أو الشريحة (`ICCID` / `IMSI`)، مع زر نسخ فوري وربط تلقائي باستعلام الرصيد.
- **إدارة متكاملة للأجهزة المتصلة والسابقة والمحظورة (`DevicesManagerPanel`)**:
  - تبويبات مستقلة لعرض **الأجهزة المتصلة الآن**، و**الأجهزة التي سبق اتصالها**، و**قائمة الأجهزة المحظورة**.
  - عرض الاسم، وعنوان `IP`، وعنوان `MAC` (مع النسخ)، ونوع ومدة الاتصال، وشارة `جهازك الحالي` مع التحديث التلقائي كل بضع ثوانٍ.
- **حظر فعلي ومؤكد عبر `MAC Address`**:
  - زر حظر وفك حظر مباشر لكل جهاز + نافذة **حظر يدوي عبر `MAC Address`** مع حماية تمنع حظر الهاتف الحالي بالخطأ.
  - التحقق الفعلي من ذاكرة المودم (`uapx_wlan_mac_filters` / `ACL_mac_list` / `mac-filter`) بعد إعادة تهيئة الواي فاي للتأكد من تنفيذ الحظر أو فك الحظر فعلياً قبل تأكيد العملية للمستخدم.
- **دقة بيانات حقيقية 100% والتعامل الذكي مع الانقطاع**:
  - عدم عرض أي أرقام تقديرية أو افتراضية عند غياب المعلومة من المودم.
  - مراقبة حية لحالة الاتصال (`isConnectionLost`) لمنع عرض البيانات القديمة على أنها مباشرة، مع إعادة اكتشاف ومصادقة تلقائية فور عودة الاتصال بالمودم.

## البنية البرمجية
- `lib/models/modem_models.dart`: نماذج البيانات الموحدة والتحقق الصارم من رقم الخدمة.
- `lib/services/modem_detector.dart`: الكشف التلقائي وربط مآخذ الشبكة بواجهة `wlan0`.
- `lib/services/adapters/`: محولات البروتوكولات (`notion_mifi_adapter.dart`, `zte_goform_adapter.dart`, `huawei_hilink_adapter.dart`, `universal_translator_adapter.dart`, `demo_modem_adapter.dart`).
- `lib/services/app_controller.dart`: إدارة الجلسة، التحديث التلقائي، كشف الانقطاع، والتحكم المؤكد بالأجهزة.
- `lib/widgets/devices_manager_sheet.dart`: لوحة إدارة الأجهزة المتصلة والسابقة والمحظورة والحظر اليدوي عبر `MAC`.
